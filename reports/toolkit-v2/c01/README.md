# C01 source evidence

Each JSON file records a repository commit, commit date, fetched source URLs,
SHA-256 hashes and source-only status. `latest_release_observed` is independent
metadata; it does not bind a release binary to the inspected commit. HTTP errors
remain explicit. No package was installed or executed.

Read [the decisions](../../../docs/aeep-toolkit/UPSTREAM_MATRIX.md) for scope and
remaining conformance work. OpenSkillEval was located through its arXiv v2 project
site; its README distinguishes Apache-2.0 code from CC-BY-NC-4.0 benchmark data.
No benchmark data was downloaded.
