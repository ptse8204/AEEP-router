# Read and control the current local Toolkit delivery

Use this guide to identify the result you are reviewing and the setup it actually
changed. The Toolkit delivers a local Python CLI with private HTML/Markdown
reports. It reuses agent-skill-eval for scripted evaluation and the existing AEEP
managed evaluator where the tested upstream Codex contract did not meet requirements.
Waza and LangGraph are optional, tested fixture integrations. No hosted service or
orchestrator is required for this local path.

## Actual pause and undo boundaries

This completed comparison enabled no persistent host connection, automatic
candidate use, project activation or background service. The reviewed proxy is
stopped and the task workers have exited. There is no running comparison to pause
and no native project activation to undo. Do not execute a terminal driver again.

The [exact C13 control walkthrough](production-readiness-20261021/CONTROL_CHECK.md)
shows the supported `assess cancel`, `assess status` and private `remove` interfaces.
It asks you to run help only, without changing a completed job or installation.

For a future interrupted managed run, preserve the canonical attempt, receipt,
usage and partial effects. Stop new dispatch and use the existing assessment
recovery path before considering another attempt. An error or cancellation does
not establish absence of effects. The [managed run guide](../../../docs/aeep-toolkit/MANAGED_EVALUATION.md)
describes incomplete operation records and report-only export. This guide does
not invent a general pause command or authorize an uncertain retry.

The private installation tests already removed their unchanged runtimes. If you
later install another reviewed private wheel runtime, use its exact installation
record and supported `remove` interface in [installation controls](../../../docs/aeep-toolkit/INSTALLATION_DESIGN.md#implemented-private-wheel-runtime).
Stop processes using that runtime first. Removal preserves changed trees and
keeps its journal/lock; it is not permission to delete a virtual environment or
configuration manually. No global installation or Codex authentication was changed
by these checks. Retain images, volumes, backups and evidence unless separately
reviewed and authorized for cleanup.
