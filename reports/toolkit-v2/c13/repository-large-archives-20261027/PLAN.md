# Preserve compact profiles and support larger real repositories

The completed pool has51 cases and90 remain. The diverse-source sample retained
sixteen of twenty archives only partially because they exceeded650000 compressed
bytes. Another sample had nineteen of thirty over that cap. Those are operational
transport exclusions, not evidence that the tasks or capabilities lack value.

Before any holdout freeze, add a separately reviewed suite-case v5 archive profile.
Keep v1-v4 meanings, limits, mapper and recipe serialization intact. Reuse the
existing AEEP container, protected grader, upstream pytest/parser and artifact
transport. An upstream harness replacement would not remove the same local
transport limits and would add a separate execution boundary. No new core service,
installer, model framework or database is justified.

Proposed finite engineering bounds are3500000 compressed source/test bytes,
20000000 expanded file bytes,24000000 raw tar bytes,5000 members and7000000 grader
payload bytes. They are a fit hypothesis for public repository snapshots, not
production SLOs or scientific acceptance thresholds. The contained command wrapper
needs an explicit operator-owned larger input allowance because its current
outer ceiling is2000000. Keep old wrappers unchanged, cap expanded wrappers and
bind all settings through existing executor fingerprints. The reviewed host frame
maximum is configurable up to16777216; a later actual worker profile needs its own
applicable conformance. No live source or worker evidence transfers automatically.

The larger public archive mapper must have an explicit operator adapter version.
Model arguments and candidate patches cannot enlarge it. Missing tests, test/config
edit protection, path and decompression checks, exits, budgets, licenses,141-case
balance and qualification/usefulness thresholds remain. Improve archive prefix
conflict checking without weakening it before permitting more members.

First validate code with bounded synthetic archives, truthful schema exports,
old recipe reconstruction and input-wrapper fixtures. Then run the repository's
required source checks. Bounded read-only source sizing can inform the next review;
new third-party execution, installs, images and model disclosure still need their
specific authorization. The51 historical cases retain exact old bindings.
