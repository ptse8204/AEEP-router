# Assembled stack audit and delivery correction

The reusable managed stack exists in pieces, and has executed real comparisons.
Recent repository campaigns assembled it with experiment-specific drivers rather
than demonstrating a reusable operator workflow. The new `workflow` CLI selects
hash-bound plan/source configurations and delegates to the existing managed
entry point. Its tests establish that interface; a fresh real-worker demonstration
through it remains outstanding.

The [machine audit](audit.json) records all 21 catalog/support entries, reviewed
source and artifact pins, retained rights records and hashes of the inspected
interfaces/evidence. It records package metadata separately. No live runtime,
container, service or installed inventory was probed. Historical execution is not
current-source conformance. The [original worksheet](../../c01/review-worksheet.json)
retains platform, permissions, footprint, install/removal and redistribution limits;
this audit does not re-clear licenses or dependencies.

## Three separate acceptance decisions

1. Stack integration: pending actual current-source end-to-end execution through
   the reusable interface. Software fixtures and historical components are recorded
   separately. The interface adds no conformance or qualification shortcut.
2. Candidate usefulness: not established for the proposed differentiated specialists.
   Existing Ponytail results remain negative/inconclusive for their scopes.
3. Selection usefulness: unproven. Actual admission refusals establish restraint,
   not a gain from choosing capabilities by task.

The [workflow guide](../../../../docs/aeep-toolkit/STACK_DELIVERY.md) gives the
commands, configuration contrasts and independent gate requirements. Candidate
specialists are Ruff safe fixes and LibCST codemods on repository maintenance.
The rationale is different executable mechanisms, not an expectation that a new
candidate must win. Qualification, optional-use comparison, bundle comparison and
selection comparison retain separate evidence and existing formal thresholds.
