# Bounded metadata sample — source data only

Twenty new repository groups were sampled from pinned public metadata, with eight
proposed audits, six multi-file repairs and six single-file repairs. Bounded reads
retained11,740,861 bytes. Sixteen archives exceeded650,000 compressed bytes and
were retained as partial bytes without parsing. Four need static source/license/
runtime review. No source, installer, test or model ran; no case was adopted.

The sample preferred sparse declared package lists. Empty metadata does not mean
no dependencies or a small runtime. The following named library sample corrects
that planning limitation without rewriting this selection or increasing bounds.
